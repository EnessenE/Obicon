Server configuration and enroll tokens

Server settings

Settings pinned by appsettings or environment variables are forced and read-only. Other settings are stored in the server database.

Enroll tokens

Nodes can register themselves with a valid enroll token (requires the NodeAutoEnrollmentEnabled setting). The plain token is shown only once at creation; the server stores only its hash.
